# ⚡ E-CELL – Virtual Electrochemistry Lab

An interactive Engineering Chemistry learning application built with Python and Streamlit.

## Modules

- 🏠 Home
- 🔋 Galvanic Cell Simulator
- 🧮 Nernst Equation Calculator
- ⚡ Gibbs Free Energy Calculator
- 📚 Theory & Quiz

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Project concept

The application demonstrates galvanic cells, standard cell potential, the Nernst equation, Gibbs free energy, theory notes and a self-assessment quiz.

## Example

For the Daniell cell:

- E°(Cu²⁺/Cu) = +0.34 V
- E°(Zn²⁺/Zn) = −0.76 V
- E°cell = +1.10 V
- n = 2
- At Q = 1 and 298 K, Ecell = 1.10 V
- ΔG ≈ −212.3 kJ mol⁻¹

Educational simulation only; it does not reproduce all physical laboratory effects.
